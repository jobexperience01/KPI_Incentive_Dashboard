📊 KPI & Incentive Dashboard

For any department: define your own KPI criteria, record data daily or monthly, see employee-wise scores and the incentive split, then download PDF or Excel. Everything runs in your browser.

📖 Guide — how to start a new department from scratch

The Television Production department is pre-loaded as a working example (default settings). Follow these steps to build your own department the same way.

Quick start (8 steps)
  1. Add your department. In 1 · Setup, open the Department dropdown → ➕ Add new… → type the name. You get an empty workspace with a starter category and 3 starter criteria. Add your Plant and Section the same way.
  2. Create employee categories. Open the Employee category dropdown → ➕ Add new… for each group that is judged differently (e.g. Executive, Officer, Manager). Each category has its own criteria, employees and incentive pool.
  3. Define the criteria. In 2 · Criteria edit, add (+ Add criterion) or remove (✕) rows until they describe how your people are judged. Set each weight (all weights should total 100), the target and the input source.
  4. Add employees. In 3 · Employees press + Add employee, type ID and name and pick a designation (add new designations from the same dropdown).
  5. Enter the data. Criteria set to Manual entry are typed straight into the employee table. Criteria set to Record log are filled automatically from entries you add in 4 · Log (daily or weekly).
  6. Check the dashboard. 5 · Dashboard shows each employee’s score and grade; 6 · Incentive splits the pool. Set the pool and minimum score in the category settings.
  7. Download. Choose this category, all categories combined, or separate files — as PDF or Excel.
  8. Next month. Import last month’s Excel at the top. Departments, categories, criteria, employees and logs return and the period moves forward; add only the new data.
How each criterion type is scored
  • Higher is better — full weight when the value reaches the target, proportional below it (sales %, cards earned, supervisor marks out of 10).
  • Lower is better — full weight up to the target (tolerance), falling in a straight line to 0 at the zero-score value (late days, complaints, errors, red cards, disciplinary cases).
  • Below category average — full weight at or below the category’s average (or a fixed target if you set one); reduces above it (leave days).

Score = Σ(weight × result) ÷ Σ weights × 100. Grades: A ≥ 90 (100%), B ≥ 80 (80%), C ≥ 70 (60%), D ≥ 60 (40%), E < 60 (0%). Incentive = pool × (score × grade factor) ÷ the total for all eligible employees in the category.

Example: a Sales department
Category “Sales Executive” → criteria: Sales achievement % (higher, weight 50, target 100, manual) · Customer complaints (lower, weight 20, target 0, zero at 5, log) · Late days (lower, weight 10, target 1, zero at 4, log) · Manager rating /10 (higher, weight 20, target 10, manual). Good to know
  • Your work is saved in this browser automatically. Download the Excel file regularly as a backup and for next month’s import.
  • Only Excel files downloaded from this page can be imported.
  • The “Load production defaults” button in 2 · Criteria restores the original production criteria for a category.
  • Removing a department or category deletes its employees and log — the ✕ button asks for a second tap.

Pick last month’s Excel file downloaded from this app. The department, categories, criteria, employees, dropdown lists and logs come back automatically, and the period moves to the next month.
